# 企鹅工坊使用指南

> Penguin UI - PenguinPebbling  
> AI 图像生成与创意管理工作台

---

## 一、产品概述

企鹅工坊（Penguin UI）是一款基于 AI 的图像生成工具，支持多种创意模式，让用户可以快速生成高质量图片。

### 核心特性

- **多模式图像生成**：支持普通模式、BP模式（蓝图变量）、Smart模式
- **创意库管理**：本地/云端创意库，支持收藏、导入导出
- **桌面式工作区**：Mac风格的图片管理界面，支持文件夹和叠放
- **多API支持**：云端服务 / 贞贞API / Gemini本地
- **明暗主题**：自动适配深色/浅色模式

## 三、核心功能

### 3.1 图像生成

#### 普通模式
1. 上传参考图片（可选）
2. 在提示词框中描述想要的画面
3. 设置画面比例和分辨率
4. 点击生成按钮

#### BP模式（蓝图模式）⚡
BP模式是一种变量模板系统，适合需要频繁修改部分参数的场景。

**特点：**
- 使用 `/变量名` 定义手动输入变量
- 使用 `{变量名}` 定义AI智能体变量（自动填充）
- 黄色标签标识BP创意

**使用步骤：**
1. 在创意库中选择一个BP模板
2. 填写左侧面板中的变量输入框
3. 点击生成，系统会自动替换变量生成完整提示词

### 3.2 创意库

创意库是模板管理中心，存储可复用的提示词模板。

| 功能 | 说明 |
|------|------|
| 新增 | 创建新的创意模板 |
| 编辑 | 修改已有模板 |
| 收藏 | 收藏常用模板（⭐ 星标） |
| 导入/导出 | JSON格式批量管理 |
| 拖拽排序 | 自定义排列顺序 |

**筛选分类：**
- **全部**：显示所有创意
- **BP**：只显示BP模式创意

### 3.3 桌面工作区

类似 macOS 的图片管理界面：

- **图片项**：生成的图片自动保存到桌面
- **文件夹**：组织整理图片
- **叠放**：多张图片堆叠显示
- **拖拽**：自由摆放位置
- **双击**：预览大图 / 打开文件夹

### 3.4 历史记录

底部历史条显示最近生成的图片：
- 点击可加载历史记录
- 支持再次编辑和重新生成
- 自动保存到本地 IndexedDB

## 四、API 配置

### 4.1 云端服务
登录后自动使用云端API，余额使用🪨鹅卵石计费。

### 4.2 贞贞API（第三方）
1. 点击设置按钮 ⚙️
2. 展开「贞贞API配置」
3. 填写 API Key
4. 点击「获取Key」注册账号
5. 保存配置后启用

### 4.3 Gemini 本地
1. 在设置中填写 Gemini API Key
2. 适合本地调试，不消耗云端额度

## 七、常见问题

### Q: 生成失败怎么办？
1. 检查网络连接
2. 确认API配置正确
3. 查看是否有余额（云端模式）
4. 尝试简化提示词

### Q: 如何迁移创意库？
使用导出功能下载 JSON 文件，在新设备上导入即可。

### Q: 图片保存在哪里？
图片保存在浏览器的 IndexedDB 中，清除浏览器数据会丢失。建议及时下载重要图片。
