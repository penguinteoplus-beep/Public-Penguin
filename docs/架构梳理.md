## 一、技术栈概览

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | React 18 + TypeScript | 类型安全的组件化开发 |
| 构建工具 | Vite | 快速开发与构建 |
| 样式方案 | TailwindCSS | 原子化CSS，支持主题切换 |
| 本地存储 | IndexedDB | 创意库、历史记录持久化 |
| 状态管理 | React Context | 主题、任务状态管理 |
| API通信 | Fetch API | 支持多种后端服务 |

## 三、核心模块架构

### 3.1 App.tsx - 主应用（约3200行）

App.tsx 是整个应用的核心，采用"胖组件"模式集中处理逻辑：

```
App.tsx
├── 状态管理
│   ├── 用户状态 (currentUser, apiKey)
│   ├── 创意库状态 (localCreativeIdeas, cloudCreativeIdeas)
│   ├── 生成状态 (status, generatedContent, prompt)
│   ├── 桌面状态 (desktopItems, selectedIds)
│   └── UI状态 (view, modals)
│
├── 子组件
│   ├── LeftPanel          # 左侧面板（参数配置）
│   ├── Canvas             # 中央主区域
│   ├── RightPanel         # 右侧面板（收藏/最近）
│   ├── BPModePanel        # BP模式变量输入
│   └── SmartPlusDirector  # Smart+导演模式
│
├── IndexedDB操作
│   ├── openDB / getAllFromDB / saveToDB / deleteFromDB
│   └── history 相关操作
│
└── 核心处理函数
    ├── handleGenerateClick      # 生成图片
    ├── handleUseCreativeIdea    # 使用创意模板
    ├── handleToggleFavorite     # 收藏切换
    └── ...
```

## 五、API 模式切换

```typescript
type ApiMode = 'cloud' | 'local-thirdparty' | 'local-gemini';

// 优先级判断逻辑
function getCurrentApiMode(): ApiMode {
  if (currentUser) return 'cloud';
  if (thirdPartyApiConfig.enabled) return 'local-thirdparty';
  if (apiKey) return 'local-gemini';
  return 'cloud'; // fallback
}
```

## 七、样式体系

### 7.1 颜色规范

```css
/* 主题色 - Blue系 */
--accent: #3B82F6;        /* blue-500 主色 */
--accent-light: #60A5FA;  /* blue-400 浅色 */
--accent-dark: #2563EB;   /* blue-600 深色 */

/* BP模式 - Amber系 */
--bp-color: #F59E0B;      /* amber-500 */
--bp-light: #FBBF24;      /* amber-400 */

/* 禁用色 */
/* 不再使用 cyan 系 (#06B6D4) */
```

### 7.2 组件规范

- 使用 `theme.colors.*` 动态取色
- 圆角统一使用 `rounded-lg` / `rounded-xl` / `rounded-2xl`
- 阴影使用 `shadow-lg shadow-{color}-500/25`
- 毛玻璃效果 `backdrop-blur-xl`

## 十、扩展建议

4. **性能优化**：大量图片考虑虚拟滚动
